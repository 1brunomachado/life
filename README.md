# Sesc Life

A plataforma digital de saúde integral do Sesc.

Mente, corpo e prevenção em uma só plataforma. Jornadas personalizadas com especialistas reconhecidos em saúde e bem-estar, conectando anamnese inicial, agenda inteligente e suporte contínuo com o cuidado do Sesc.

Videoaulas, trilhas personalizadas, agenda inteligente e integração com as unidades Sesc e Senac.

**Produção:** https://www.sesc-rs.com.br/life

## Comandos

| Comando             | Ação                                      |
| :------------------ | :---------------------------------------- |
| `npm install`       | Instala as dependências                   |
| `npm run dev`       | Inicia o servidor local em `localhost:4321` |
| `npm run build`     | Gera o build de produção em `./dist/`     |
| `npm run preview`   | Pré-visualiza o build localmente          |
